# Remove-GraphEvent
## SYNOPSIS
Removes a calendar event via Microsoft Graph.

## SYNTAX
### __AllParameterSets
```powershell
Remove-GraphEvent -UserPrincipalName <string> -EventId <string> [-Connection <GraphConnectionInfo>] [-TimeoutSeconds <int>] [-RetryCount <int>] [-RetryDelayMilliseconds <int>] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
Removes a calendar event via Microsoft Graph.

## EXAMPLES

### EXAMPLE 1
```powershell
Remove-GraphEvent -UserPrincipalName 'Name' -EventId 'Value'
```
