# New-MimeMessage
## SYNOPSIS
Creates a MIME message without requiring callers to construct MimeKit types directly.

## SYNTAX
### __AllParameterSets
```powershell
New-MimeMessage [-From <string>] [-To <string[]>] [-Cc <string[]>] [-Bcc <string[]>] [-Subject <string>] [-TextBody <string>] [-HtmlBody <string>] [-AttachmentPath <string[]>] [-Header <hashtable>] [<CommonParameters>]
```

## DESCRIPTION
Creates a MIME message without requiring callers to construct MimeKit types directly.

## EXAMPLES

### EXAMPLE 1
```powershell
New-MimeMessage -AttachmentPath @('C:\Path')
```
