# New-GraphEventBuilder
## SYNOPSIS
Creates a GraphEventBuilder instance.

## SYNTAX
### __AllParameterSets
```powershell
New-GraphEventBuilder [-Subject <string>] [-Start <DateTime>] [-StartTimeZone <string>] [-End <DateTime>] [-EndTimeZone <string>] [-Body <string>] [-BodyType <string>] [-Attendees <string[]>] [<CommonParameters>]
```

## DESCRIPTION
Creates a GraphEventBuilder instance.

## EXAMPLES

### EXAMPLE 1
```powershell
New-GraphEventBuilder -Attendees @('Value')
```
